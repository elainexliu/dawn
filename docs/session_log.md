# Session Log Format

Each recording session produces three files under `data/raw/` and `data/labeled/`:

```
data/raw/<session_id>.bin
data/raw/<session_id>.meta.json
data/raw/<session_id>.markers.csv
data/labeled/<session_id>.candidates.csv   (generated by emg_candidate_flagger)
data/labeled/<session_id>.labels.csv       (generated by review_tool)
```

---

## `<session_id>.bin`

Raw packet bytes concatenated in receive order.
Each record is either 37 bytes (IMU+PPG+Thermal) or 11 bytes (EMG, not currently streamed), exactly as defined in `docs/packet_format.md`.
No additional framing or headers between packets.

Reading: scan for `0xAA`, read TYPE byte, consume the remaining fixed number of bytes.

---

## `<session_id>.meta.json`

Written at session start; updated with end-time and packet counts on exit.

```json
{
  "session_id":    "2026-07-07_001",
  "port":          "COM3",
  "baud":          921600,
  "start_utc":     "2026-07-07T14:32:00.123456+00:00",
  "end_utc":       "2026-07-07T15:01:45.987654+00:00",
  "pkt_version":   1,
  "imu_ppg_packets": 91500,
  "emg_packets":   915000
}
```

| Field            | Type   | Notes                                      |
|------------------|--------|--------------------------------------------|
| `session_id`     | string | Unique identifier; typically `YYYY-MM-DD_NNN` |
| `port`           | string | Serial port used                           |
| `baud`           | int    | Baud rate                                  |
| `start_utc`      | string | ISO-8601 host wall-clock time at session start |
| `end_utc`        | string | ISO-8601 host wall-clock time at session end |
| `pkt_version`    | int    | Firmware packet version byte               |
| `imu_ppg_packets`| int    | Count of valid IMU+PPG packets decoded     |
| `emg_packets`    | int    | Count of valid EMG packets decoded         |

---

## `<session_id>.markers.csv`

Keypress events logged during recording.
**All timestamps are ESP32 `millis()` values** from the most recently decoded packet — not host wall-clock time.

```csv
timestamp_ms,event
12345,marker
67890,marker
```

| Column         | Type   | Notes                                        |
|----------------|--------|----------------------------------------------|
| `timestamp_ms` | int    | ESP32 `millis()` of last decoded packet at keypress |
| `event`        | string | Currently always `"marker"`; extensible      |

Use these timestamps to define regions of interest before labeling.

---

## `<session_id>.candidates.csv`

Auto-detected EMG activity windows, generated by `host/labeling/emg_candidate_flagger.py`.

```csv
start_ms,end_ms,peak_emg
12000,12400,8192
34200,34900,11000
```

| Column      | Type | Notes                                    |
|-------------|------|------------------------------------------|
| `start_ms`  | int  | Window start, ESP32 `millis()`           |
| `end_ms`    | int  | Window end, ESP32 `millis()`             |
| `peak_emg`  | int  | Peak absolute ADS1115 raw count in window |

---

## `<session_id>.labels.csv`

Human-reviewed labels, generated by `host/labeling/review_tool.py`.

```csv
start_ms,end_ms,label
12000,12400,1
34200,34900,0
```

| Column     | Type | Notes                                              |
|------------|------|----------------------------------------------------|
| `start_ms` | int  | Window start, ESP32 `millis()`                     |
| `end_ms`   | int  | Window end, ESP32 `millis()`                       |
| `label`    | int  | `1` = BFRB / tic urge present,  `0` = non-event   |

**Clock domain note:** All timestamps across `.bin`, `.markers.csv`, `.candidates.csv`, and `.labels.csv` are in ESP32 `millis()` space.  No host wall-clock times appear in any label file.  The `start_utc` / `end_utc` in `.meta.json` are for human reference only and are never used in feature extraction or training.
